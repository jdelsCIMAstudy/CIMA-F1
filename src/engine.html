The app hasn't started

You're probably seeing this in a preview viewer (for example the Files app on iPhone, or a chat attachment preview). Those show the page but don't run it.

Fix: open this file in a full browser.

  • iPhone: tap Share → "Open in…" or "Save to Files", then open it from Chrome, or long-press the file in Files → Share → Safari/Chrome.
  • Android: open it with Chrome ("Open with" → Chrome).

If it is open in a full browser and you still see this, check that JavaScript is on in the browser settings.
